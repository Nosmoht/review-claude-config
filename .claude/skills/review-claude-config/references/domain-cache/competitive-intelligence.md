# Competitive Intelligence — Domain Best Practices

- **Intelligence Cycle adherence:** Planning & Direction, Collection, Processing, Analysis, Dissemination. Each phase should have quality gates.
- **Actionable insight mandate:** "Insight without a next step is just noise" — every CI deliverable must end with a recommendation.
- **AI + CI convergence (2025-2026):** Automated collection with human-in-the-loop analysis is the emerging standard.
- **Ethical collection:** SCIP Ethics Guidebook mandates public-source-only collection, no misrepresentation, transparent methodology.
- **Knowledge management:** Structured repositories supporting incremental updates rather than periodic reports.
- **Source triangulation:** Minimum 2-3 independent sources per claim before it enters a deliverable.
