# Public Sector Procurement — Domain Best Practices

- **EU thresholds (2026-2027):** EUR 140K (central gov) / EUR 216K (sub-central) for services; IT services under CPV Division 72.
- **eForms mandatory since Oct 2023:** All TED notices use eForms standard (EU 2019/1780); TED API v3 returns BT-* field identifiers.
- **SME lot-splitting requirement:** GWB mandates splitting large contracts into lots unless technically/economically justified.
- **Vergabebeschleunigungsgesetz (Aug 2025):** Raised direct-award thresholds, simplified verification, central digital procurement platform planned.
- **DTVP reach:** 30K+ daily notices, 1.8M bidder profiles; supports CPV-filtered search URLs. AI-powered classification in rollout.
- **TED API:** POST-only for search, no auth required for public notices, BT-* eForms convention.
- **Key German portals:** TED (EU-wide), service.bund.de (federal), DTVP (aggregator), evergabe.de, ITDZ Berlin, Dataport, BWI.
- **Eligibility patterns:** Turnover requirements, reference project counts, geographic presence; Eigenerklaerung increasingly accepted.
