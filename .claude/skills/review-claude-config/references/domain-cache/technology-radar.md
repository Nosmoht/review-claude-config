# Technology Radar — Domain Best Practices

- **Quadrants:** ThoughtWorks uses Techniques, Platforms, Tools, Languages & Frameworks. Custom radars may redefine quadrants.
- **Rings:** Adopt, Trial, Assess, Hold — represent recommendation strength, not maturity. Ring assignment is opinion-driven by senior practitioners.
- **Process:** ThoughtWorks TAB (24 senior technologists) meets biannually face-to-face. Consensus-based, informed by real project experience. Published twice yearly.
- **Cross-validation:** ThoughtWorks radar is explicitly opinionated from practitioner experience. Requiring 2+ sources is a reasonable adaptation for LLM-driven research where hallucination risk replaces practitioner judgment.
- **Build Your Own Radar:** Open-source tool at radar.thoughtworks.com accepting CSV/JSON (name, ring, quadrant, isNew, description).
- **2025-2026 themes:** Context engineering, MCP protocol adoption, agentic systems growth, AI-accelerated shadow IT risks, structured output as anti-hallucination technique. Vol 33 (Nov 2025) is latest.
- **Anti-patterns:** Complacency with AI-generated code, insufficient human oversight, AI-driven shadow IT.
